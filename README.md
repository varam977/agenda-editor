# VARAM · Agenda

Agenda tipo editor de vídeo para iPhone: días de curro (edición de vídeo, webs 3D, extras de camarero, Vinted y salario), facturación por mes y gastos.

- **Calendario**: cada trabajo es una línea de color con su nombre corto (EDITOR, VINTED, SUELDO…). Leyenda arriba con lo del mes.
- **Facturas**: cuentas del mes como un ticket, «Por cobrar» de todos los meses con botón ✓ COBRADO, círculo de dónde viene el dinero y filtros.
- **Gastos**: IA y personales juntos, con círculo de porcentajes. Cada uno se resta de lo suyo (IA → vídeo y webs, personales → salario).
- **Fijos**: ingresos y gastos fijos se repiten solos cada mes (también el mes siguiente). El sueldo puede marcarse «se cobra solo».

Abrir en Safari → Compartir → Añadir a pantalla de inicio. Los datos se guardan solo en el móvil (exporta copia desde ⚙).
